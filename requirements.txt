# static-only mode. skillspector is not on PyPI; it is pinned to an immutable
# commit so builds are reproducible. Bump the @<sha> + rebuild the image to
# update the ruleset/scanner version. skillspector pulls its own heavy tree
# (langgraph / langchain / openai / yara-python) transitively.
